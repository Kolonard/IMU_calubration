# Инструкция по использованию программ с меткой времени от NTP-сервера

Есть два файла и они запускаются на двух системах:
- `ntp_server_stable.bat` на компьютере, выступающим в роли сервера с NTP метками (Приоритетно использовать Windows 10/11)
- `ntp_client_vista_stable.bat` на компьютере, принимающим метки времени (Стенд поворотного стола)

Далее будем говорить просто сервер и клиент, подразумевая 2 разных компьютера.

## Предварительная подготовка
Сервер и клиент должны быть подключены к одной локальной сети и иметь свои IPv4 адреса

## Сервер
Порядок действий:
1) Запустить от имени администратора `ntp_server_stable.bat`
2) Дождаться выполнения программы в терминале
3) Перезапустить компьютер-сервер
4) Запустить cmd через `Win+R` и ввести команду ```ipconfig```
5) Узнать IPv4 адрес сервера (что-то вроде `192.168.137.1`) и запомнить его
6) Чтобы убедиться, что NTP сервер поднят, стоит отдельно в cmd написать ```w32tm /query /status``` и после этого ```netstat -an | find ":123"```. Если там указан IP `0.0.0.0:123`, то все успешно запущено.

## Клиент (Windows Vista)
ВАЖНО: Перед запуском отредактировать `ntp_client_vista_stable.bat` и в самом верху найти переменную `set NTP_SERVER=` и заменить IP адрес на тот, который мы узнали с помощью `ipconfig` с сервера

Порядок действий:
1) Запустить от имени администратора `ntp_client_vista_stable.bat`
2) Дождаться выполнения программы в терминале
3) Перезапустить компьютер-клиент
4) Чтобы убедиться в правильности работы программы на Windows Vista стоит еще раз проверить, что источником для меток синхронизации выступает наш NTP сервер, а не локальные часы (`Local CMOS Clock`). Для этого выполнить в cmd команду:
```w32tm /query /source``` и если выводится IP адрес NTP сервера, то всё успешно. Если не IP сервера, то прописать команды:
```
w32tm /config /syncfromflags:manual
w32tm /config /manualpeerlist:"192.168.137.1,0x8"  (здесь заменить на IP сервера)
net stop w32time
net start w32time
w32tm /query /source
```
Все должно заработать и выдавать айпи сервера: `192.168.137.1,0x8`


## Дополнительные команды:
- если было обнаружено, что задержка стала сильно возрастать между клиентом и сервером, то стоит прописать в cmd от имени администратора команду ```w32tm /resync /rediscover```
- для настройки переход в спящий режим можно использовать команды:
```
powercfg /change standby-timeout-ac 60
powercfg /change standby-timeout-dc 60
```
где вместо `60` указать значение в минутах для перехода компьютера в сон


## Глобально важно
Чтобы избежать сильной рассинхронизации надо:
- не уводить компьютеры в сон
- держать Ethernet активным
- периодически делать resync (интеграция в скрипт была бы кстати)
